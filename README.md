# Persian Dark Horse

Source code for the Persian Dark Horse / FEZI AI website. The frontend is in `artifacts/fezi-ai`, the API server is in `artifacts/api-server`, and shared libraries are in `lib`.

## Run locally

This is a full-stack application, not a GitHub Pages-only site. It requires its API server, database, and separately configured environment secrets to work. GitHub hosts the source; it does not run the application or include production credentials.

Install dependencies with `pnpm install`, then run the frontend and API server using their scripts (see each artifact’s `package.json`).
